# 🏫 智慧學校成績管理與跨班分析系統 (GAS 雙軌整合旗艦版)

> **專為國高中導師與科任教師打造的 Google Apps Script (GAS) 雲端全方位成績管理系統。**  
> 整合了 **Gemini AI 手寫照片自動辨識與線上校對**、**Excel 每日自動排程匯入**、**導師成績總表維護**、**導師班全科學習曲線與微觀診斷**、**科任教師三維度跨班分析儀表板**，以及**家長獨立安全查詢端與 QR Code 分享**。

---

## 🌟 系統亮點特色

### 1. 🌟 教師全功能主控台 (`TeacherHub`)
* **三合一整合工作站**：單一現代化網頁介面，無縫切換三大核心教學工具：
  1. 📸 **手寫成績單 AI 辨識與校對匯入**：直接在網頁端批次上傳多張手寫成績單照片，透過 Gemini Vision AI 辨識並產生線上即時校對表格。確認無誤後一鍵寫入導師總表或對應科任分頁。
  2. 📊 **導師班級主控版**：
     * **全科學習歷程曲線**：自動載入最前至今日成績區段，繪製多科目平時測驗趨勢折線圖。
     * **班級統計看板**：即時精算班平均、及格率、最高/最低分、標準差（齊次度）。
     * **個人微觀深度診斷 (2x2 四大圖表)**：
       * 📈 學生個人歷次成績趨勢線。
       * 🪜 0~6 階五標能力階梯圖（精準對位 PR 區間）。
       * 🎯 跨學科/單元能力雷達圖。
       * ⚖️ 個人學習穩定度與偏態分佈。
  3. 🔬 **科任跨班分析主控版**：深度整合 `SubjectDashboard`，提供同年段跨班多維比較分析。

### 2. 🔬 科任班級三維度深度跨班分析
* **五碼智慧解析**：支援 `國二愛理化`、`高一忠物理`、`101理化` 自動解析年級、班級與科目。
* **Macro View (跨班橫向比較)**：
  * **年段母群常模五標堆疊圖**：以**同年段同科目全體學生**為母群計算統一五標標準（頂標 P88、前標 P75、均標 P50、後標 P25、底標 P12），各班依此常模精準統計五標梯隊佔比。
  * **跨班走勢多折線圖**：即時對照各班測驗均分走勢與年段平均虛線。
* **Auto-Alert (滾動式預警標記清單)**：
  * 🔴 **高風險 (Crisis)**：最新成績 $<50$ 分，或連續 2 次低於班級底標。
  * 🟡 **顯著退步 (Warning)**：最新成績較前 3 次均分退步 $>15$ 分。
  * ⚡ **高波動 (Unstable)**：個人標準差 $SD > 18$，成績忽高忽低缺乏穩定性。
  * 🟢 **顯著進步 (Growth)**：最新成績較前 3 次均分大幅提升 $>15$ 分。
  * 點擊任意學生「🔍 檢視」按鈕，立即精確跳轉該生「學習歷程卡」。
* **Micro View (個人學習歷程卡)**：
  * 個人得分 vs 班級均標 vs 年段平均對比線。
  * **90 度直角能力雷達圖**：評量類別僅有 2 項時自動改為直角 90 度扇面，避免 180 度退化為一條線；背景疊加全年段五標基準線。

### 3. 🔒 企業級雙重安全防護與家長端分離
* **教師端 PIN 碼防護**：
  * 外部瀏覽器存取 `TeacherHub` 時，需輸入教師專屬安全 PIN 碼（預設 `1234`，可於 `System_Settings` 自由自訂），防範家長或學生誤入。
  * 於 Google 試算表內部開啟主控台對話框時，系統自動識別授權，**免輸 PIN 碼**直接開啟。
* **家長獨立查詢端 (`?view=student`)**：
  * 預設 Web App 網址為教師主控台，家長端採用獨立參數路由 `?view=student`，徹底隱藏教師後台與管理功能。
  * 支援輸入學生座號與密碼，即可安全查閱個人成績與分析圖表。
* **短網址與 QR Code 一鍵分享**：
  * 後端自動調用 TinyURL API 與 QRServer 產生家長查詢端縮短網址與 350x350 高解析度 QR Code。
  * 支援一鍵複製、下載 QR Code、列印家長通知單與教室張貼海報。

### 4. ⚙️ 高度集中化設定 (`System_Settings`)
* 統一在試算表設定全域參數（Gemini API Key、上傳/備份資料夾 ID、隨機背景圖與校徽、教師 PIN 碼）與班級跨檔對照表，維護時無需修改程式碼。

## 📐 試算表標準分頁格式規範

### 1. `[System_Settings]` 基礎設定分頁
> 💡 *可透過試算表上方選單「🏫 導師成績管理」$\rightarrow$「🛠️ 建立/檢查 [System_Settings] 基礎設定分頁」一鍵自動建立。*

* **全域參數設定區 (A:B 欄)**：
  | A 欄：項目 (Key) | B 欄：設定值 (Value) | 說明 |
  | :--- | :--- | :--- |
  | `TEACHER_PIN` | `1234` | 教師主控台外部登入 PIN 碼 (請自行更改) |
  | `GEMINI_API_KEY` | `AIzaSy...` | Google Gemini API 金鑰 (用於手寫成績單辨識) |
  | `UPLOAD_FOLDER_ID` | `1A2b3C...` | 傳統 Excel / 手寫照片上傳區 Google Drive 資料夾 ID |
  | `BACKUP_FOLDER_ID` | `4D5e6F...` | 已處理檔案自動歸檔備份區資料夾 ID |
  | `BG_FOLDER_ID` | `7G8h9I...` | 查詢端隨機背景底圖與學校 LOGO 資料夾 ID |
  | `LOGO_KEYWORD` | `logo` | 校徽圖片檔名關鍵字 (例如 `school_logo.png`) |

* **班級與跨檔對照表 (D:H 欄)**：
  | D: Class_Code | E: Homeroom_SS_ID | F: Target_Sheet_Name | G: Key_Column_Name | H: Subject_Column |
  | :---: | :---: | :---: | :---: | :---: |
  | `101` | `1A2b3C...` (101導師檔 ID) | `導師成績總表` | `座號` | `理化` |
  | `102` | `9Z8y7X...` (102導師檔 ID) | `導師成績總表` | `座號` | `理化` |
  | `103` | `3M4n5O...` (103導師檔 ID) | `導師成績總表` | `座號` | `理化` |

---

### 2. `[導師成績總表]` 分頁範本
* **A1 儲存格**：班級名稱防呆驗證（例如 `101` 或 `101班`，必須與對照表或班級名稱相符）。
* **A 欄**：查詢密碼（學生身分證末四碼或自訂密碼，從第 4 列開始）。
* **B 欄**：座號（從第 4 列開始：1, 2, 3...）。
* **C 欄**：學生姓名。
* **D 欄起**：歷次測驗成績資料（每一欄代表一次測驗）：
  * **第 1 列**：科目名稱（如：國文、英文、數學、理化、生物...）。
  * **第 2 列**：測驗範圍（如：第一課單元卷、第一章力與運動...）。
  * **第 3 列**：測驗日期（格式規範：`YYYY-MM-DD`，如：`2026-10-15`）。
  * **第 4 列至學生末列**：學生成績數值（0~100，缺考請填空白或 0）。

---

### 3. 科任班級分頁格式範本 (五碼命名)
* **分頁命名規則**：固定五碼格式，前 2 字為年級，中間 1 字為班級，後 2 字為科目。
  * 範例：`國二愛理化`、`國二仁理化`、`高一忠物理`、`101理化`（三碼班級相容模式）。
* **欄位結構**：
  * **A1 儲存格**：班級名稱（例如 `國二愛`）。
  * **A 欄**：座號（從第 4 列開始：1, 2, 3...）。
  * **B 欄**：學生姓名。
  * **C 欄起**：歷次科任測驗成績：
    * **第 1 列**：評量類別（如：`平時小考`、`第一次段考`、`隨堂測驗`）。
    * **第 2 列**：測驗範圍（如：第一單元力學）。
    * **第 3 列**：測驗日期（格式：`YYYY-MM-DD`）。
    * **第 4 列起**：學生得分。

## 🚀 試算表選單與功能操作指引

在 Google 試算表上方會自動註冊三大功能選單：

### 一、 🌟 教師主控台選單
1. **🚀 開啟教師全功能主控台 (辨識匯入 / 導師主控 / 科任主控)**：
   * 彈出 `TeacherHub` 整合工作站，免輸入 PIN 碼直接使用（支援手寫成績單 AI 辨識、導師班級微觀學習曲線、科任三維度跨班分析，並可於主控台頂部一鍵產生家長專屬 QR Code 與分享短網址）。
2. **📖 產生/更新系統操作說明與範本分頁**：
   * 一鍵在當前試算表中自動建立或美化更新 **`系統操作說明與範本`** 分頁，包含完整使用手冊與標準格式表格。

### 二、 🏫 導師成績管理選單
1. **📥 執行每日匯入 (自動路由分頁)**：
   * 自動排程或手動觸發，掃描雲端硬碟手寫照片與 Excel 檔，自動路由匯入分頁並發送 Gmail 報告。
2. **📥 匯入當前分頁成績至導師總表 (5字解析比對)**：
   * 當手動登記某專任分頁（如 `101理化`）後，切換至該分頁點選此功能，自動比對 A1 防呆並寫入導師總表。
3. **📊 產生指定區間歷史成績單**：
   * 彈出日期挑選對話框，預設自動帶入最早測驗日期至今日，支援加權平均與排名結算。
4. **🖨️ 匯出區間個人報表 (列印/PDF)**：
   * 產生批次成績通知單（`BatchReport`），包含學習雷達圖、五標常模落點，支援一鍵列印或匯出 PDF。
5. **⚙️ 設定科目/類別加權值**：
   * 自訂各科加權比重，支援拖曳或上移/下移進行成績單輸出排序。
6. **📦 結算並匯出舊學期資料 (開新學期)**：
   * 學期結束時一鍵將舊成績備份至獨立試算表，保留學生名冊乾淨開啟新學期。
7. **🛠️ 建立/檢查 [System_Settings] 基礎設定分頁**：
   * 檢查設定分頁與對照表完整性，自動補齊缺少欄位。

### 三、 🏫 成績管理工具 (專任端)
1. **📤 同步當前科任成績至導師試算表 (跨檔動態開啟)**：
   * 任教多班時，自動透過 `System_Settings` 對照表開啟各班導師試算表，比對 A1 後跨檔同步成績。
2. **📈 開啟科任跨班分析儀表板 (視覺化)**：
   * 獨立彈出 `SubjectDashboard` 進行跨班橫向比較、自動預警與個人歷程微觀分析。
3. **📑 產出科任跨班分析總表分頁**：
   * 將分析儀表板統計成果直接輸出成試算表分頁 **`科任跨班分析總表`** 留存。
4. **🍎 計算平均與區間人數**：
   * 針對當前分頁成績，智慧判斷「僅對尚未計算之欄位」進行即時統計補充。
5. **🔀 按評量類別排序欄位 (當前班級)**：
   * 依據第 1 列評量類別與日期自動重排成績欄位。

## 🛠️ 安裝與部署指南

1. **建立 Google 試算表**：
   * 開啟 Google 雲端硬碟，建立新的 Google 試算表。
2. **開啟 Apps Script 編輯器**：
   * 點選上方選單 **「擴充功能」** $\rightarrow$ **「Apps Script」**。
3. **貼上專案檔案**：
   * 依序建立並貼入：
     * `Code.gs`
     * `TeacherHub.html`
     * `SubjectDashboard.html`
     * `Index.html`
     * `BatchReport.html`
     * `DateRangeDialog.html`
     * `WeightSettingDialog.html`
4. **初始化系統設定**：
   * 重新整理試算表，點選選單 **「🌟 教師主控台」** $\rightarrow$ **「📖 產生/更新系統操作說明與範本分頁」**。
   * 點選選單 **「🏫 導師成績管理」** $\rightarrow$ **「🛠️ 建立/檢查 [System_Settings] 基礎設定分頁」**。
   * 於 `System_Settings` 填入您的 Gemini API Key、資料夾 ID 與自訂 `TEACHER_PIN`。
5. **部署為 Web 應用程式**：
   * 點選 Apps Script 右上角 **「部署」** $\rightarrow$ **「新增部署作業」**。
   * 類型選擇 **「網路應用程式 (Web App)」**：
     * **說明**：成績管理系統正式版
     * **執行身分**：我 (您的 Google 帳號)
     * **誰可以存取**：所有人 (Anyone)
   * 點選 **「部署」** 並複製 Web App 網址。
6. **每日定時自動排程 (可選)**：
   * 於 Apps Script 左側點選 **「觸發條件 (鬧鐘圖示)」** $\rightarrow$ **「新增觸發條件」**：
     * 執行函式：`importDailyScores`
     * 活動來源：**「時間驅動」**
     * 類型：**「每日定時器」**（建議：凌晨 2:00 ~ 4:00）
