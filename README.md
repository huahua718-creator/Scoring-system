# 🏫 智慧學校成績管理與跨班分析系統 (GAS 雙軌整合版)

> **專為國高中導師與科任教師打造的 Google Apps Script (GAS) 雲端全方位成績管理系統。**  
> 整合了 **Gemini AI 手寫照片自動辨識**、**Excel 每日自動排程匯入**、**導師成績總表維護**、**學生週平時成績 Web App 查詢端**，以及全新的 **科任教師三維度跨班分析儀表板**。

---

## 🌟 系統特色

1. **雙軌核心設計**：
   * **導師端**：統整全班各科平時測驗、週加權平均計算、週排名、區間成績單與個人報表 PDF/列印匯出、舊學期資料自動歸檔。
   * **科任端**：五碼分頁智慧解析（如 `國二愛理化`、`高一忠物理`）、跨班宏觀橫向比較（Macro View）、自動化預警（Auto-Alert）、個別學生學習歷程卡（Micro View）。
2. **高度集中化設定 (`System_Settings`)**：
   * 統一維護 Gemini API Key、雲端硬碟資料夾 ID（上傳區/備份區/背景圖/LOGO）以及跨班導師試算表對照表。未來更換金鑰或資料夾無需碰觸程式碼！
3. **AI 視覺手寫辨識與 Excel 自動路由**：
   * 拍照手寫成績單或上傳傳統 Excel 檔案至 Google Drive，系統每日自動定時掃描並將成績自動路由至導師總表或對應科任分頁，執行完畢自動發送 Gmail 報表。
4. **現代化互動 Web App 端**：
   * 學生/家長端：輸入座號與密碼，即可查看個人週成績、全歷史 100 分制雷達/趨勢圖與 0~6 階梯五標相對常模圖表。
   * 科任教師儀表板：多班折線走勢圖、班級五標能力結構堆疊柱狀圖、滾動式預警標記清單。

## 📐 試算表分頁規劃與版型規範

### 1. `[System_Settings]` 基礎設定分頁
> 💡 *可透過試算表上方選單「🏫 導師成績管理」$\rightarrow$「🛠️ 建立/檢查 [System_Settings] 基礎設定分頁」一鍵自動建立。*

* **全域參數設定區 (A:B 欄)**：
  | A 欄：項目 (Key) | B 欄：設定值 (Value) | 說明 |
  | :--- | :--- | :--- |
  | `GEMINI_API_KEY` | `AIzaSy...` | Google Gemini API 金鑰 |
  | `UPLOAD_FOLDER_ID` | `1A2b3C...` | 成績上傳區資料夾 ID |
  | `BACKUP_FOLDER_ID` | `4D5e6F...` | 已處理檔案備份區資料夾 ID |
  | `BG_FOLDER_ID` | `7G8h9I...` | 查詢端隨機背景底圖與 LOGO 資料夾 ID |
  | `LOGO_KEYWORD` | `logo` | 校徽圖片檔名關鍵字 (例如 `school_logo.png`) |

* **班級與導師試算表對照表 (D:H 欄)**：
  | D: Class_Code | E: Homeroom_SS_ID | F: Target_Sheet_Name | G: Key_Column_Name | H: Subject_Column |
  | :---: | :---: | :---: | :---: | :---: |
  | `101` | `1A2b3C...` (101導師檔 ID) | `導師成績總表` | `座號` | `理化` |
  | `102` | `9Z8y7X...` (102導師檔 ID) | `導師成績總表` | `座號` | `理化` |
  | `103` | `3M4n5O...` (103導師檔 ID) | `導師成績總表` | `座號` | `理化` |

---

### 2. `[導師成績總表]`
* **A 欄**：查詢密碼（學生身分證末四碼或指定密碼）。
* **A1 儲存格**：班級標題（例如 `101` 或 `101班`，作為防呆驗證依據）。
* **B 欄**：座號（從第 4 列開始：1, 2, 3...）。
* **C 欄**：姓名。
* **D 欄起**：歷次測驗成績：
  * **第 1 列**：科目名稱（國文、英文、數學、理化...）。
  * **第 2 列**：測驗範圍（如：第一單元小考）。
  * **第 3 列**：測驗日期（格式：`YYYY-MM-DD`）。
  * **第 4 列至學生末列**：學生成績。

---

### 3. 科任班級分頁五碼命名規範
系統依據固定五碼格式自動辨識並歸類「同年段、同科目」群組：
$$\text{分頁名稱} = \underbrace{\text{前 2 字}}_{\text{年級}} + \underbrace{\text{中間字}}_{\text{班級}} + \underbrace{\text{後 2 字}}_{\text{科目}}$$
* **範例**：
  * `國二愛理化` $\rightarrow$ 年級：`國二`、班級：`愛`、科目：`理化`
  * `國二仁理化` $\rightarrow$ 年級：`國二`、班級：`仁`、科目：`理化`
  * `高一忠物理` $\rightarrow$ 年級：`高一`、班級：`忠`、科目：`物理`
* **科任分頁欄位規範**：
  * **A 欄**：座號（第 4 列開始）。
  * **B 欄**：姓名。
  * **C 欄起**：歷次測驗成績（第 1 列為評量類別如 `小考`/`段考`、第 2 列為範圍、第 3 列為日期）。

## 🚀 功能操作指引

### 一、 導師端功能 (選單：「🏫 導師成績管理」)
1. **📥 執行每日匯入 (自動路由分頁)**：
   * 自動掃描上傳資料夾內的手寫照片（Gemini AI OCR 辨識）與 Excel 試算表，自動路由寫入總表或專任分頁，備份歸檔並發送信件。
2. **📥 匯入當前分頁成績至導師總表 (5字解析比對)**：
   * 當導師手動登記某科任分頁（如 `101理化`）後，切換至該分頁點選此功能。
   * 系統自動比對導師總表 `A1` 儲存格班級防呆，確認科目、範圍與日期後自動寫入總表新欄位。
3. **📊 產生指定區間歷史成績單**：
   * 依據選定的起訖日期，自動篩選區間測驗，計算該區間的加權平均、加權總分與排名。
4. **🖨️ 匯出區間個人報表 (列印/PDF)**：
   * 產生全班或個別學生的個人成績通知單網頁，支援一鍵列印或另存 PDF。
5. **⚙️ 設定科目/類別加權值**：
   * 彈出介面自訂國文、英文、數學各科在導師總表之計算加權。
6. **📦 結算並匯出舊學期資料 (開新學期)**：
   * 學期結束時，一鍵將目前所有成績另存為獨立備份試算表，並重置總表欄位，保留名冊乾淨開啟新學期。

---

### 二、 科任端功能 (選單：「🏫 成績管理工具」)
1. **📈 開啟科任跨班分析儀表板 (視覺化)**：
   * 彈出互動視窗，支援右上角下拉切換年段科目群組（如 `國二 理化`）。
   * **Tab 1: 跨班橫向與趨勢比較 (Macro View)**：
     * 跨班指標對照表（應考人數、班平均、及格率、標準差/齊次度徽章、頂底標率）。
     * 跨班歷次測驗走勢多線圖（各班折線 + 年段平均虛線）。
     * 班級能力結構堆疊長條圖（頂標/前標/均標/後標/底標佔比）。
   * **Tab 2: 自動化預警清單 (Auto-Alert)**：
     * 🔴 高風險 (Crisis)：最新 $<50$ 分或連續 2 次低於班底標。
     * 🟡 顯著退步 (Warning)：較前 3 次均分下滑 $>15$ 分。
     * ⚡ 高波動 (Unstable)：個人 $SD > 18$ 成績忽高忽低。
     * 🟢 顯著進步 (Growth)：較前 3 次均分進步 $>15$ 分。
     * 點擊任意學生「👁️ 檢視」直達歷程卡。
   * **Tab 3: 個別學生學習歷程卡 (Micro View)**：
     * 個人得分 vs 班級均標 vs 年段平均 走勢對比。
     * 評量類別能力雷達圖。
     * 本學期預警與進步軌跡時間軸 (Timeline)。
2. **📑 產出科任跨班分析總表分頁**：
   * 將儀表板數據直接輸出成試算表實體分頁 **`科任跨班分析總表`**，方便備份或分享。
3. **📤 同步當前科任成績至導師試算表 (跨檔動態開啟)**：
   * 專任教師任教多班時，在自己的試算表切換至 `101理化`，系統透過 `System_Settings` 對照表自動開啟 101 班導師試算表，比對 A1 防呆後跨檔寫入！

---

### 三、 Web App 網頁端存取
* **學生/家長查詢端**：
  * 直接開啟 Web App 部署網址（例如：`https://script.google.com/macros/s/.../exec`）。
  * 輸入座號與密碼即可查詢本週成績、歷史趨勢圖與五標常模。
* **科任教師全螢幕儀表板**：
  * 在 Web App 網址後方加上參數：
    `https://script.google.com/macros/s/.../exec?page=dashboard`（或 `?mode=subject`）。
  * 適合使用大螢幕電腦直接全螢幕瀏覽操作。

## 🛠️ 安裝與部署指南

1. **建立 Google 試算表**：
   * 開啟 Google 雲端硬碟，建立新的 Google 試算表。
2. **開啟 Apps Script 編輯器**：
   * 點選上方選單 **「擴充功能」** $\rightarrow$ **「Apps Script」**。
3. **貼上專案檔案**：
   * 將本專案中的 `Code.gs`、`Index.html`、`SubjectDashboard.html`、`BatchReport.html`、`DateRangeDialog.html`、`WeightSettingDialog.html` 分別新增並貼入對應程式碼。
4. **初始化設定分頁**：
   * 重新整理試算表，點選選單 **「🏫 導師成績管理」** $\rightarrow$ **「🛠️ 建立/檢查 [System_Settings] 基礎設定分頁」**。
   * 在 `System_Settings` 分頁中填入您的 Gemini API Key、資料夾 ID 與各班導師試算表 ID。
5. **部署為 Web 應用程式**：
   * 點選 Apps Script 右上角 **「部署」** $\rightarrow$ **「新增部署作業」**。
   * 種類選擇 **「網路應用程式 (Web App)」**：
     * **說明**：成績管理系統正式版
     * **執行身分**：我 (您的 Google 帳號)
     * **誰可以存取**：所有人 (Anyone) 或 您的機構內使用者
   * 點選 **「部署」**，複製產生的 Web App 網址。
6. **設定每日自動排程 (可選)**：
   * 在 Apps Script 左側點選 **「觸發條件 (鬧鐘圖示)」** $\rightarrow$ **「新增觸發條件」**：
     * 選擇要執行的功能：`importDailyScores`
     * 選取活動來源：**「時間驅動」**
     * 選取時間型觸發條件類型：**「每日定時器」**（例如：凌晨 2:00 ~ 3:00）
